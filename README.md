# Campus Event Management System

## Project Overview
A web-based portal designed for university students to view, search, and register for campus events. Built as a collaborative project using Git & GitHub workflows.

## Team Members
- **Student 1 (Team Lead):** Repository Admin, GitHub Management, PR Reviews, Deployment
- **Student 2 (Frontend Developer 1):** Main Layout, HTML Structure, Navigation, CSS Styling
- **Student 3 (Frontend Developer 2):** Search Bar, Category Filters, Modal Authentication
- **Student 4 (Frontend Developer 3):** Event Management, Registration State & LocalStorage
- **Student 5 (Frontend Testing & Documentation):** Documentation, Testing, and UI Responsiveness

## Features
- Dynamic Event Listings (Seminars, Workshops, Sports, Competitions)
- Search and Category Filtering
- Student Registration System
- Admin Panel to Create New Events
- Mobile Responsive Design

## How to Run Locally
1. Clone this repository: `git clone <repository-url>`
2. Open `index.html` directly in any web browser.
